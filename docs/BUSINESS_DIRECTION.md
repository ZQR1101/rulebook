# Rulebook（暂名）· 业务方向定稿

定稿日期：2026-09-11。本文档是产品的业务基准：所有范围决策与本文冲突时，以本文为准或先修订本文。

## 一、解决的问题

组织里有一类重复发生的工作：**把一份非结构化文档，对照一套"标准"逐条检查，给出结构化判定，再交给下一环节签字或执行**。典型场景：

- **供应商合同合规**：采购/法务对照公司标准（账期、责任上限、数据存储地、SLA、审计权等）逐条审合同。人工一份 2–4 小时，审累了变成盖章，小合同跳过审查直接签。
- **客户交付件风险分析**：咨询交付负责人处理客户的 SOW / 服务请求 / 变更申请，判断完整性、风险、缺失信息。全靠个人经验，交接丢上下文，审批无记录。

这类工作有五个结构性失败，且都不是"人更努力"能解决的：

1. **慢**——审查是人工瓶颈，一份文档小时级。
2. **判定不一致**——标准存在于审阅者脑中，两人同审一份文档结论可能不同。
3. **无证据**——判定不给原文依据，无法复核。
4. **不可审计**——谁在何时按什么标准判的，事后查不到。
5. **漏检无兜底**——漏看条款是静默失败；标准在文档里找不到对应内容时没有任何机制亮灯。

## 二、产品定义

> **给小团队的"规则手册驱动文档审查平台"**：文档进来，引擎按可编辑的规则手册逐条体检，产出**每条判定都带原文引用**的红黄绿记分卡；红/黄必须专家签字才定稿；全程审计、可自然语言追问。**换业务域只换剧本（规则手册），不改代码。**

### 一个引擎 + 两套剧本（同时落地）

引擎六段流水线（两剧本共用）：`入口 → 解析 → 逐条评分 → 记分卡 → 签字门 → 交付物 + 审计 + 追问`

| | 剧本一 · 供应商合同合规 | 剧本二 · 客户交付件风险分析 |
|---|---|---|
| 业务来源 | Microsoft Agent Academy Operative Track 冠军 VendorGuard 的闭环 | 同赛道第二名 Engagement Hub 的治理内核 |
| 用户 | 采购/法务 | 咨询 PM / 交付负责人 |
| 规则手册 | 15 条规则 × 5 维度（商业/法律/数据隐私/SLA/监管） | 资质标准：风险标记、缺失信息、置信度阈值 |
| 交付物 | 合规审查 Word 报告 + xlsx 记分矩阵 | 需求调研简报 + Word 交接文档 |
| 量化叙事 | 人工 2–4 小时 → 分钟级 | 分析从半天 → 分钟级 |

### 治理内核（六条硬约束）

1. **强制引用门**：每条判定必须引用文档原文，无引用自动降级为"待人工"。
2. **签字门**：红/黄判定必须专家批准，报告才可定稿导出。
3. **全程审计**：append-only 审计日志，correlation ID（文档 ID + 条款 ID）贯穿。
4. **幂等去重**：上传按内容哈希去重；通知与记录创建幂等。
5. **失败路径显式建模**：解析失败 / LLM 失败 / 证据不足都有明确状态、原因和重试入口。
6. **三路径测试**：happy / duplicate / failure 全部自动化测试。

## 三、定位与边界

- **小团队版**：账号密码登录，两种角色——管理员（规则手册增删改、用户管理，兼审批）与评审专家（审批队列、改判、追问、导出）。
- **入口**：Web 上传（第一入口）+ 本地监听文件夹（自动收件，零接触叙事）；IMAP 邮件为二期。
- **中文优先**界面，中英混排文档解析；买方视角起步。
- **本期不做**：多租户、规则自动挖掘、OCR 评分增强（IMAP/SMTP 已在 v1.1 落地；PyPI 包已构建并验证但未公开上传，分发走源码安装）。

## 四、为什么相信这是真问题

1. 微软 Agent Academy Hackathon Operative Track 冠亚军正是这两个闭环（VendorGuard 全场最高分验证闭环价值；Engagement Hub 验证人工门与审计带来可信度）。
2. 相邻市场已付费验证：安全问卷自动应答（Conveyor 约 1 万美元/年起，SafeBase、Vanta 等）本质同构——"对照标准审文档出判定"。
3. 成本账可算：外审数千元/份 × 每月十几份，远大于自建工具成本。

## 五、量化指标（产品自身的验收口径）

- 覆盖正确率：应判定的规则被判且判定有据的比例。
- 拒答正确率：文档未覆盖的规则被正确标红（而非编造"绿色"）的比例。
- 引用命中率：引用指向的条款确实包含相关内容的比例。
- 端到端时延：上传 → 记分卡可审阅的时间。

## 六、演示叙事

> 一份 30 条的供应商合同，人工查两小时；上传后几分钟出带引用的记分卡，红灯自动进签字队列。规则手册改一条，下一份合同立即生效。再切到"客户交付件"剧本——引擎一行代码没动。
